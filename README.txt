# Shahed's Portfolio Website

## Files
- `index.html`: Home page
- `contact.html`: Contact Me page
- `style.css`: CSS styling for both pages
- `script.js`: JavaScript form validation and success alert
- `images/profile.jpg`: Profile photo

## Preview locally
Open `index.html` in a web browser. Use the navigation menu to open Contact Me.

## Publish with GitHub Pages
1. Create a GitHub account. The assignment says the GitHub username should match the username part of your JUST email.
2. Create a repository named `YOUR-GITHUB-USERNAME.github.io`.
3. Upload all files and folders in this project. Keep `index.html` in the repository's root folder.
4. In the repository, open Settings > Pages.
5. Choose the deployment source/branch offered by GitHub (usually `main` and `/ (root)` for a new repository), then save.
6. Wait for deployment and open `https://YOUR-GITHUB-USERNAME.github.io/`.

## Important notes
- Replace any personal text if you want to customize it before publishing.
- The contact form validates the fields and shows the required success alert. It does not send/store messages on a server; the assignment only asks for validation and an alert.
- The profile image is included in `images/profile.jpg`.
